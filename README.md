# skeeks/cms-ai

Панель SkeekS AI для сайтов на SkeekS CMS: чат сотрудника в админке, контекст карточки, вложения, память и навыки сайта, общие файлы проекта.

**Состояние:** внутренний пилот, не выпущен. Подключается только на локальном стенде.

Целевое устройство: пакет сайта обращается к центральному сервису SkeekS AI (`skeeks/cms-ai-service`) через API v1 и не хранит историю чатов — она живёт в центральном сервисе. План и решения — [platform-plan, crm/ai.md](https://github.com/skeeks-cms/platform-plan/blob/main/crm/ai.md) и [crm/ai-technical.md](https://github.com/skeeks-cms/platform-plan/blob/main/crm/ai-technical.md).
